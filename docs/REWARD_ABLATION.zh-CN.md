## 奖励变化

旧奖励为前进／横向高斯跟踪项与单独偏航跟踪项相加。不动时仍可以获得偏航对齐奖励。4 mm/s直行指令、忽略物理惩罚时，不动得到约0.114，理想跟踪0.15。

新奖励先构造一个联合误差：

E = ((vx-vx*) / max(|vx*|,0.004))² + 0.25 ((vy-vy*)/0.004)² + 0.5 ((wz-wz*)/0.02)²。

跟踪项为 0.1 × clip(1-E, 0, 1)。动作变化、滑移与机械功惩罚保持原数值。仿真真速度仅用于奖励／评估，没有加入策略观测。没有强制摆动、规定相位或轨迹平移。

4 mm/s直行时，静止／2 mm/s／4 mm/s／8 mm/s的无惩罚跟踪项分别为0／0.075／0.1／0。停止指令仍奖励静止。单独改变偏航对齐不能再在完全不前进时获得独立奖励。

## 2026-10-06：修正快速小幅摆动与指令跟踪配置

此前第96轮策略实际关节在4–12秒窗口的主频约4.625 Hz，2 Hz以上功率占79%–92%；停止命令仍有明显前移。它说明“产生了运动”，不能说明学会了速度控制。旧轨迹没有保存请求角度、限速后的目标和实际力矩，不能从小幅摆动直接推断舵机力矩不足。

本轮增加 `smooth_v3` 控制配置及 `tracking_v3` 奖励，保留原默认配置和正在运行的旧奖励对照。

| 项目 | 本轮处理 | 验证目的 |
|---|---|---|
| 关节命令 | 10 Hz策略输出，50 Hz一阶平滑，时间常数0.2秒；仍限制目标变化率1 rad/s | 减少策略交替指令造成的快抖，保留低频摆动 |
| 可用幅值 | 候选目标上限由±20°改为±25°；启动训练前须通过8秒受载波形检查 | 排除控制范围过小，同时保留实际角度26°和轮间包络2 mm保护 |
| 跟踪奖励 | 原来的 `clip(1-E,0,1)` 改为 `1/(1+E)` | 不再把所有较大误差压成相同的零分；这不等于证明它必然更易收敛 |
| 动作代价 | 惩罚平滑前、裁剪后的请求动作一阶和二阶差分 | 让快速反向本身付出代价，而不只看平滑后的目标 |
| 奖励测量 | 十块隔板几何中心的平移、首尾连线的偏航；滤波时间常数0.2秒 | 降低单块隔板局部摇摆对整机速度评价的干扰；该中心不是质量中心 |
| 指令训练 | 每5秒重采样速度/转向命令 | 覆盖行进中的停车、启动和转向切换，避免只从静止初态学习 |
| 独立评估 | 停止、直行、左转、右转，以及先行进后停车 | 用实际速度、滑移、角度、目标跟踪和力矩记录判断效果 |

直接PPO仍只有4个蛇形关节动作，10个绳索目标保持零；未加入CPG、规定蛇形相位或“大角度加分”。指令仍为前进速度0/4/8 mm/s与偏航角速度0/±0.02 rad/s，横向速度为零，停车时偏航指令为零；尚未扩展到任意平面速度控制。

令动作 `a` 为裁剪到[-1,1]的四维请求，`Δa=a_t-a_(t-1)`、`Δ²a=Δa_t-Δa_(t-1)`，新奖励为：

```text
E = ((vx-vx*)/max(|vx*|,0.004))²
    + 0.5 ((vy-vy*)/0.004)² + ((wz-wz*)/0.02)²
r = 0.1 [1/(1+E) - 0.05 mean(Δa²) - 0.025 mean((Δ²a)²)
         - 0.02 slip/0.01] - 0.01 work_proxy
```

## 2026-10-10：步态奖励 v1 设计与门检验

当前 `tracking_v3` 只有整体速度跟踪、动作变化、滑移和功代理，没有后退蠕动波、周期/相位/幅值、蛇形正弦拟合或传播方向奖励。负向 `vx` 只会把整体质心后退当作正确答案，不能证明形变波从头向尾传播；现有四维动作映射也把五节收绳限制成线性梯度，不能表达独立的五节波。

新原型位于 `experiments/snake_gait_reward_v1_20261010/`，没有覆盖旧实验。它按照 Isaac Lab 的独立 RewardTerm 思路把 `vx`、`vy`、`wz` 和停机单独记录；加入五节压缩波的形状、周期、幅值、方向、连续性项；加入四个蛇形关节/曲率的空间正弦拟合；滑移、功、间隙和碰撞各自成为物理项。模式 0（蠕动）和模式 1（蛇形）使用较强的对应形状项，模式 2（混合）只使用很弱的形状正则，主要由速度、接触和能耗决定，避免把“混合步态涌现”硬编码为两条手工波的相加。

公式、权重、实现和引用见该目录的 `README.md` 与 `gait_rewards.py`。GPU 服务器上的数值自检已通过：独立速度项排序、2 s 后退蠕动波的形状/周期项、空间正弦拟合、碰撞/能耗惩罚和混合门控均为有限值；本地没有 PyTorch，因此自检在已授权 RTX 5090 服务器的 `/root/steel-snake-gpu/experiments/snake_gait_reward_v1_20261010/` 运行。

这还不是训练结果。要真正比较三种步态，下一步必须先把动作接口改成十个收绳通道和四个蛇形关节的独立动作（或波参数控制器加 14 维残差），加入可部署的相位时钟，再按“速度基准 → 纯蠕动 → 纯蛇形 → 混合”四阶段训练。混合是否出现新步态，要用留出轨迹的空间相位梯度、频谱峰、正弦拟合残差、滑移和单位距离能耗聚类判定，不能用总奖励或一段视频直接宣称。
