# 五体节钢片机器人：物理、控制与学习架构

更新：2026-10-05。本文对应 `train.py`、`experiment.json` 和 `../physics_core_20261003/v2_gpu/gpu_core.py` 的代码核查。当前三组短训练是接口与学习可行性试验，不代表动力学已验证或策略已收敛。

## 1. 迁移的是什么

Liu 的控制研究：[Reinforcement Learning of CPG-regulated Locomotion Controller for a Soft Snake Robot](https://arxiv.org/pdf/2207.04899)。物理仿真参考：[A Validated Physical Model For Real-Time Simulation of Soft Robotic Snakes](https://arxiv.org/pdf/1904.02833)。两者分别提供控制组织方式与耦合动力学参考，不应当混为一个算法。

| 部分 | Liu 机器人 | 我们机器人／当前实现 |
|---|---|---|
| 主体 | 四个气动硅胶柔性节 | 五个预弯钢片体节，十块隔板，四个节间摆动关节 |
| 柔性材料 | 硅胶连续体 | 四十片钢片，当前用随形梁候选模型，初始几何作为无应变参考 |
| 驱动 | 拮抗气腔、压力输入 | 十个收绳舵机、四个摆动舵机；当前纯蛇形训练只开放后四个 |
| CPG 输出接口 | 转成气动输入 | 转成有限角度、速度和力矩的关节目标；不是压力数值照搬 |
| 状态感知 | 视觉目标相对状态及柔性节曲率 | 部署分支为编码器＋陀螺仪；文献迁移分支为模拟视觉＋节间等效曲率 |
| 地面作用 | 单向轮产生方向相关运动特征 | 被动轮自转、滚阻、理想单向离合、正则化黏着／滑移；参数未标定 |

不能把四个刚性连接关节角称为四个软体节曲率，也不能把 FOC 的振荡性质直接等同于我们的机器人运动效果。

## 2. 应采用的闭环

```text
任务指令（体坐标速度，或有定位时的目标点）
  ↓
策略：直接 PPO / 固定 CPG / RL 调节 CPG
  ↓
驱动分配：四个摆动角；将来加入十个收绳命令
  ↓
执行器：目标变化率、速度—力矩能力、延迟、负载
  ↓
共同物理状态：隔板＋钢片＋绳索＋节间连接＋轮子＋地面
  ↓                               ↓
模拟传感器 → 策略观测              仿真真值 → 奖励、失效判定、独立评估
```

策略不能直接修改隔板位置、钢片形状、机器人平移速度或轨迹。CPG 只产生驱动命令；运动必须来自执行器做功与接触反力。

三种模态最终共用同一个物理模型：纯蛇形开放四个摆动驱动、固定十个收绳命令；纯蠕动开放十个收绳驱动、四个摆动关节保持中位；融合模态再联合控制十四个驱动。十四个驱动不意味着必须有十四个独立振荡器，振荡器数量由节律与驱动映射决定。

## 3. 力如何耦合，以及当前求解缺口

目标组织形式是共同广义状态 q 下的动力学平衡：

M(q) v_dot + h(q,v) = f_steel + f_tendon + f_joint + f_ground + f_gravity。

该式是架构表达，不表示现有代码已完整实现所有配置相关惯性项。

钢片当前弹性能为 U = 1/2 (u-u0)^T K (u-u0)，弹性广义力使用 -J^T K (u-u0)。参考形状 u0 来自初始化，只有实际预弯钢片无载形状匹配时，才能解释为实物自然形状。当前切线为 J^T K J，省略应力相关几何 Hessian；惯性与能量预算仍需验证。

每根绳索当前使用：

- e = L(q) - L0(servo)。
- e < 0 时张力为零；否则 T = max(0, 2000 e + 0.5 L_dot)，单位采用 SI。
- 张力作用于两端隔板，力矩为 r × F。
- 这是当前经验阻尼实现；没有显式包含 L0_dot，不能将其描述为已验证的完整可变自由长度 Kelvin–Voigt 模型。

钢片通过夹持连接给隔板反力，隔板位姿改变绳长，绳长改变张力；张力又反馈到收绳负载。因而存在双向力学反馈，当前舵机负载限速使用上一物理步的张力。还不是电机转子惯性、电流及传动的完整模型。

轮地当前法向力为 max(0, 5000 penetration - 8 v_normal)，仅穿透时激活；切向使用弹簧记忆、阻尼与 Coulomb 圆盘限幅 ||F_t|| ≤ μN。轮转动、滚动阻力及理想止逆在局部步骤处理；μ=0.8、滚阻系数0.06。止逆限制轮自转方向，不会禁止整个机器人在地面上滑退。

**重要区别：当前不等于 Gasoto 的统一 Newton 求解。** `external()` 先以当前状态计算绳索、连接与接触载荷，再将梁的线性化切线纳入速度求解；轮接触有局部隐式处理，但没有全系统外层 Newton 收敛循环。梁内部节点通过链式消元，再用 GPU `torch.linalg.solve_ex` 解缩减系统；不是 PCR。

因此“在一个时间步内相互反馈”不等于“所有非线性在同一时刻迭代收敛”。推进方向应是先量化分步误差，再决定加入全局残差迭代／更完整切线。换成 PCR 本身不会自动修复耦合误差。

## 4. 本轮实际训练

| 分支 | 策略观测 | 学习动作 | 任务 |
|---|---|---|---|
| direct | 14角度、14差分角速度、3陀螺仪、4历史应用命令、3速度指令；10帧历史 | 四个关节目标 | 速度跟踪，首轮 vy=0 |
| liu | 模拟视觉目标相对状态、四个节间等效曲率、历史动作等 | 四个 Matsuoka 互补输入 | 到点，固定 Kf=1，c=0 |
| liu_foc | 同 liu | 同 liu | 同一到点任务，c=0.75 |

物理步长0.25 ms、控制和传感50 Hz、策略10 Hz；目标角度限制±20°；两并行环境、种子7；每组最多2048个环境样本或1800秒。物理运行在 RTX5090，小型 PPO 网络在 CPU 更新。不是完整 PPOC；尚无高层频率选项学习。

2026-10-05 本次远程核查时，direct 已记录1040样本，liu与liu_foc各720样本，状态均为 training。数字仅为该次快照；以 `remote/snapshot.json` 时间戳和各组后续评估为准。

现有 direct 与 Liu 分支的任务、传感器和奖励不同，不能横向比较回报以宣称某控制器优越。现有 liu 与 liu_foc 才是同任务下的初步 FOC 消融，但单种子、短训练尚不能支持性能结论。

## 5. 下一轮应固定的比较条件

先沿用用户要求的纯蛇形速度控制作为主任务，在同一机器人、传感器、指令序列、执行器限制与训练预算下比较：直接 PPO、固定 CPG、CPG＋PPO。部署观测保持角度、差分角速度、陀螺仪、任务指令和历史命令；不加入用户已排除的比力。固定 CPG 是开环基准，应报告其同一指令序列下的响应，而不能称其具备任意速度闭环。

视觉到点作为独立研究组，比较直接 PPO、Matsuoka＋PPO、Matsuoka＋FOC＋PPO，三者使用相同模拟视觉和任务定义。之后若迁移到硬件，必须提供定位来源。仅角度＋陀螺仪不足以唯一观测持续平移滑移和目标位置。

Matsuoka 振荡器、FOC 输入可作为文献方法基线；Hopf 可作为另一个控制器基线。先验证频率、幅值和偏置经过舵机限制后如何影响真实关节响应，再开展学习，不能以振荡器输出代替实际关节运动。

## 6. 物理验证先于性能结论

1. 单钢片：无载预弯、端部弯曲／扭转刚度、卸载恢复；与独立梁解、较高保真模型或实验对照。
2. 单体节：收绳量—张力—压缩量、偏心弯曲、松绳、卸载，检查钢片反力回到隔板和绳索的闭环。
3. 单轮及轮组：自由滚动、止逆、推拉阈值、滑移、停止；不能用调摩擦追求预设速度排名。
4. 两体节：摆动关节阶跃／正弦响应、反作用力矩、支撑变化与间隙。
5. 五体节：无驱动不应持续自推进；固定波形可重复；检查时间步减半、能量／动量残差及分步耦合误差。
6. 通过物理门槛后再开展多种子控制比较、噪声与延迟扰动、参数随机化和实机标定。

当前短训练保留为接口探索证据；在物理验收前不据此报告实物速度、能效优势或可靠部署能力。完整机身／钢片自碰撞响应尚未实现，当前只有轮包络等失效保护。
