# GPU 迁移中的问题与处理

## 1. BeamAdapter 质量比例阻尼接口（已定位，GPU 默认修正）

安装版本 `AdaptiveBeamForceFieldAndMass.inl:321` 的 `addMDx` 明确忽略 `datadx`，调用的 `applyMassLarge` 始终计算 `M * gravity`。这会影响使用该接口构造的 Rayleigh 质量阻尼右端项。

验证链：GPU 与 SOFA 的装配矩阵最大差约 2e-10，但速度单步差约 0.0036；仅复现上述接口行为后，速度差降至约 2e-8，完整轨迹也重合。不是因为 GPU 精度不足。

- `sofa_mass_compat=True`：只用于复现冻结 v1 的数值结果。
- 默认 `False`：按实际速度计算质量比例阻尼。不能用兼容模式进行最终能耗评估。
- 未修改服务器原装 SOFA 库，也未覆盖 v1 历史数据。

方程使用 SOFA 官方给出的半隐式 Euler / Rayleigh 形式，质量与刚度矩阵在当前构型评估，单步线性化。参考：[EulerImplicitSolver 方程](https://www.sofa-framework.org/api/master/sofa/html/classsofa_1_1component_1_1odesolver_1_1backward_1_1_euler_implicit_solver.html)。

## 2. 钢片截面扭转常数不能用于转动惯量（已处理）

Saint-Venant 常数用于扭转刚度 `GJ`；质量矩阵需要极惯性矩 `Iy+Iz`。GPU 实现分别使用二者，与已有 StripSection 插件一致。

## 3. 旋转积分（已处理）

安装版本的 `RigidCoord.h:108` 使用 SO(3) 指数映射。GPU 改为相同形式，避免用四元数一阶归一化更新引入额外差异。

## 4. CUDA Graph 内不能临时从主机创建常量（已处理）

初次捕获失败发生在 `torch.as_tensor` 创建惯量常量时。关节偏置与惯量常量已提前传入 GPU；捕获的物理步中没有 `.cpu()`、`.numpy()` 或 SOFA 调用。每个线性求解状态在设备上累计，输出检查时才读取。

## 5. 动画抖动（已完成控制输入干预对照）

v1 是突变指令的诊断激励，舵机速度及关节目标切换会激发瞬态；还有理想止逆、黏着/滑动切换与分步接触力的影响。视频采样也会改变视觉观感。不能只凭动画归因为一种原因。

本次保存 500 Hz 的隔板速度、各轮法向力及各绳张力，比较阶跃指令与五次平滑指令，并减半时间步。只平滑控制输入，不处理计算出来的位置或视频帧。实际结果见 `summary.json` 和 `vibration_comparison.png`。

保持旧滚阻以隔离控制输入变量时，平滑输入使隔板加速度分量RMS由0.451降至0.098 m/s²，最大隔板加速度模长由12.43降至1.88 m/s²。原峰值在约0.898 s，位于舵机收缩目标到达附近。该结论不等于已消除所有柔性振动。

## 5a. 零速滚阻造成随时间步变化的人工蠕滑（已修正并做整机复查）

原模型将滚阻力矩限制为上一时刻轮角动量能提供的制动力，导致静止时无法抵抗新施加的低于阈值的驱动力。0.04 N外推力、1.4 N载荷、0.06滚阻参数时，旧模型在0.25 ms步长下持续以2.22 mm/s爬行，0.125 ms时变为1.11 mm/s。

`wheel_stiction.py` 联立轮速与滚阻力矩，补上零速可承载的状态；仍保留理想止逆，不改变摩擦/滚阻数值。五类单轮测试在三个时间步通过。五体节间距时间步RMSE由0.0908降至0.00202 mm，前进位移最大差由1.741降至0.00850 mm。

回弹残差收敛到约2.71 mm，未满足2 mm设计门槛。失败结果保留，未用降低滚阻或过滤位置来“修好”。这说明数值修正与满足机械设计要求是不同检查，后者仍需实物标定和机构验证。

## 5b. 32环境的CUDA Graph线性求解分派（已修正）

该PyTorch/CUDA组合在较大批次的`solve_ex`路径中触发Graph不允许的操作；改为GPU内按最多8环境分组求解隔板系统，结果合并仍在GPU。32环境完整Graph已通过有限状态与线性求解状态检查，并完成三次计时。未回退到CPU求解。

## 6. 本轮仍保留的模型边界

- 为单独检验计算迁移，保留 v1 的显式绳索/接触更新；尚未形成包含接触活动集的统一 Newton 求解。
- 保留 UniformMass 的固定惯量矩阵约定。大角度整机转动还需要单独审计体坐标惯量变换及陀螺项，不能用当前小摆角测试证明任意转动准确。
- 绳索是无质量轴向模型，阻尼沿端点相对速度计算；没有绳子与钢片表面接触、绳绕真实舵盘轮廓或完整电机回驱模型。
- 理想止逆轮不是带扭簧的回拉轮；不能只调摩擦系数实现二者等价。
- 钢片/隔板与障碍物碰撞、自碰撞、完整能量守恒审计和实物参数标定仍未完成。
- 当前导出的拓扑为 1/2/5 体节、每片 16 单元；批量环境不等于已训练强化学习策略。

## 7. 报告序列化（已修复）

NumPy 布尔值不能直接进入标准 JSON。验收布尔统一转换，前两次已完成积分但未写完报告的输出留在服务器 `serialization_diagnostic/`，不作为最终通过结果；完整测试重新运行。
