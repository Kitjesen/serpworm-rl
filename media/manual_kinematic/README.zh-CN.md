# 手动蛇行波形演示

五体节、四个节间偏航关节。每个关节 ±15°，周期 4 s，相邻关节滞后 90°（1 s）。视频 24 s，20 fps，1 倍速；前 4 s 用半余弦平滑增加幅值。稳态参考 q_i = 15° sin(2πt/4 − (i−1)π/2)。

本演示约定数组体节 0 为头、体节 4 为尾，波依次经过 J1→J4；实机和动力学控制接入时需要核对头尾编号及舵机符号。

由原 CAD、原钢片静止形状生成姿态，用 MuJoCo 仅渲染，再由 FFmpeg 编码。整体位置按隔板几何中心居中，并去除五体节的平均朝向，仅展示内部形状变化。没有指定向前平移，没有计算自由体动力学、钢片弹性、轮地接触或轮子转动；不能据此推断速度和实际可行性。90° 相位是便于观察的候选，并非最优结论。

- manual_snake_top_wave.mp4：俯视与紧凑的实际命令时程。
- manual_snake_top_clean.mp4：无字俯视。
- manual_snake_oblique_clean.mp4：无字斜视。
- joint_commands.csv、manual_wave.npz：命令与显示姿态。
- manifest.json：参数、检查与限制。

检查了由隔板四元数反算的相对关节角、幅值上限、稳态周期和四关节角之和。轮隙数值只对名义相邻轮几何有效，不代表全机碰撞或动力学验证。尚未修改训练配置。
