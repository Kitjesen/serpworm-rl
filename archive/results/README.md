原项目历史记录未全部复制到本仓库。历史报告中的成功与失败都保留：例如修正滚阻后的五体节诊断存在约2.71 mm残余压缩，未通过原2 mm回弹门槛，不能因为时间步结果一致而改写为设计通过。

**历史求解器增量回归：** 保持网格、材料、时间步和动作一致，静置、后退波、蛇形与融合激励各5秒的最大节点位置差8.67e-11 m、张力差2.53e-8 N。64环境完整物理步17.288→15.231 ms，吞吐提高13.5%；8环境64个策略转移的采样4.844→5.137样本/s，提高6.0%。见[可复验脚本](../../legacy/check_plate_solver.py)。短采样未包含PPO更新或20秒超时；上述为当前方程的新旧求解对照，不是新增实物验证。

下一步针对剩余几何、材料、装配和梁链消元做分项计时，再优化最大耗时项；只有改变方程、网格或时间步时，才扩大对应物理回归范围。原长训练保持旧解法，未混入此算法变更。

真正尚未完成的是完整能量／惯性一致性、统一非线性耦合、钢片与机身碰撞、实物标定及可靠的策略收敛。这些与上述已完成的数值迁移检查分别记录。

迁移前首次训练：direct采样1090步、完整更新8轮；liu与liu_foc各938步、完整更新7轮。每组约30分钟，单种子；未确认收敛。评估状态以快照文件为准。

旧 `status.json` 中的 `optimizer_updates` 实际来自 SB3 `_n_updates`（epoch计数）。新训练文件分别记录 `rollouts`、`epochs` 和真正的 Adam `optimizer_steps`，避免混淆。

历史日志和合同里的绝对路径、哈希指向当时实验；保存用于追溯，不代表本仓库具有全部历史依赖。新代码运行以根目录 README 为准。
